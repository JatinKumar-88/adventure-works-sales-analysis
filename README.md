
# Adventure Works Sales Analytics

An end-to-end data analytics project using Excel, MySQL, Power BI, and Tableau to analyze sales performance, profitability, customers, products, and regional trends.

## Project Overview

This project focuses on preparing, modelling, analyzing, and visualizing Adventure Works sales data to derive meaningful business insights.

## Objectives

- Analyze overall sales performance.
- Calculate sales amount, production cost, and profit.
- Compare sales across years, months, and quarters.
- Analyze regional sales performance.
- Identify top-performing products and customers.
- Present findings through interactive dashboards.

## Tools & Technologies

- **Microsoft Excel:** Data preparation and sales dashboard
- **MySQL:** Data preparation, joins, queries, and sales analysis
- **Power BI:** Dashboard development and data visualization
- **Tableau:** Interactive sales dashboard
- **MySQL Workbench:** Database modelling

## Project Workflow

1. Prepared and reviewed the source data.
2. Combined `FactInternetSales` and `Fact_Internet_Sales_New` using `UNION ALL`.
3. Created a combined `SALES` table containing 60,398 sales records.
4. Connected sales data with date, customer, product, and sales territory dimensions.
5. Analyzed sales, production costs, profit, time-based trends, and regional performance.
6. Developed dashboards using Excel, Power BI, and Tableau.

## Key Analysis

- Year-wise and month-wise sales trends
- Quarterly sales performance
- Sales amount and production cost calculations
- Profit analysis
- Regional sales comparison
- Top products and customers by sales
